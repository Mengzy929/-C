# 五分钟演示与数据结构说明

## 演示步骤

1. 启动 `python -m qiyan_c.demo`，打开 http://127.0.0.1:8765。
2. 说明页面标注：内容是合成样文，反馈是规则判答，没有真实引用核验。
3. 第一道题输入“不知道”提交，看到仍停留当前层；点击“给我一点提示”。
4. 点击“我想先查看解释”，先取消，说明取消不会记录放弃。再次点击并确认，展示解释后“继续下一步”仍不可用。
5. 选择段落 1，用自己的话回答缓存与查询耗时的比较，提交后才能进入下一层；反馈注明解释后重答不是独立完成。
6. 走完其他层，展示原文高亮随问题变化、五步进度和回答记录。
7. 展开学习事件，指出复习只是意向，没有调用调度服务；导出 JSON 方便检查。
8. 运行 `python tools/check.py`，展示实际测试结果和算法性能记录。

## 数据结构与算法

### 复合键哈希表与规则快照

`compile_rules` 校验全部配置后，构造 `(intent, mastery) → attempts 四档元组` 的映射，使用只读 MappingProxyType 和 tuple 防止运行中被修改。

初始化为 O(R)，其中 R 是规则条目数。每次 `decide` 平均 O(1) 查找，加上固定长度指令组装。规则文件读取不在单轮决策路径中。冷启动与纯决策耗时分开计算。

### 章节树、显式栈 DFS 与位置索引

`Section.children` 表达嵌套章节。`build_index` 使用显式栈 DFS，而不是递归查找每次定位。建索引时间 O(S+P)，额外空间 O(S+P)，S 为章节数，P 为段落数。

通过段落 ID 查找平均 O(1)，核对 quote 需 O(Q)，Q 为引用文本长度。UTF-16 偏移转换需遍历前缀，时间 O(T)，T 为段落长度；不能把整次高亮成本都写成 O(1)。

### 五层阅读有限状态机

状态包括当前层、失败次数、是否通过、是否看过解释、是否完成。普通转移为 O(1)：未通过留在原层，通过后显式前进；看过解释清除通过标记，重答后才前进。

能力掌握度、研究阶段和当前阅读层是不同概念，不能共用一个状态值。

### 有序事件序列与哈希去重

事件保存为不可变 tuple。归并时建立 ID 哈希索引，以原始顺序追加新事件，拒绝同 ID 不同内容。对 N 条已有事件与 M 条新事件，时间/额外空间均为 O(N+M)。

本实现为了纯函数和回放清晰，每次归并重建索引，**不声称整次归并 O(1)**。真实存储可使用 event_id 唯一索引保证持久化幂等。

### guard

使用有限组正则和规范化片段匹配，属于启发式规则，不是语义证明。已知答案匹配与正则的实际耗时取决于输入长度和样本数；不能用“零漏检”描述任意输入。
