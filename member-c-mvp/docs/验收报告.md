# 成员 C 独立 MVP 验收报告

日期：2026-11-03。范围：离线独立模块，不是全平台验收。

## 自动检查

在 Windows 11 / Python 3.14.6 下执行 `python tools/check.py`：43 项 unittest 方法通过，失败 0、错误 0。

- 基础决策：120 组人工指定预期组合全部匹配。
- 随机上限：固定随机种子，10000 组合法输入未违反硬上限；另测非法输入拒绝。
- guard：20 条构造违规全部被检出，20 条正常对照无误报。这些是开发样本，不是独立留出集；不用于宣称通用准确率。
- 五层阅读：全部问题有精确来源；四态反馈、同层重试、解释后重答与最终完成通过。
- 定位：文档版本、重复 ID、错误原文/位置拒绝；Unicode 码点与 UTF-16 位置转换通过。
- 事件：重复事件去重、ID 冲突拒绝、复习意向标识和时间范围通过。
- 本地驱动：重复请求不重复记事件/失败；请求内容冲突拒绝；会话隔离；HTTP 成功与错误分支通过。
- 能力：纯核心 AST 扫描未发现禁用导入/操作；有构造违规反例验证扫描器会拒绝。
- JS：执行 `node --check web/app.js` 通过。

机器可读细节及本机延迟数据见 `reports/checks.json`。纯函数决策测量不含 IO，先预热 200 次，再采样 10000 次；不是服务整体 P99，也不应外推到其他设备。

教学上下文按 UTF-8 字节估计低于预算；真实模型 tokenizer 尚未接入，不能将该估计称为真实 token 数。

## 浏览器人工操作检查

通过浏览器控制接口实际完成：

1. 初始加载与合成素材说明；首次加载段落选择按钮已修复并重新检查。
2. “不知道”反馈，留在当前层；查看提示。
3. 查看解释的弹窗：取消后没有放弃事件；确认后有三条意向事件，但仍不能前进。
4. 选择原文并重答，通过后显示“解释后重答，不计作独立完成”。
5. 完成剩余四层，出现完整阅读完成提示。

8. 该轮操作结束时浏览器 warn/error 日志为空。
9. 实际点击导出、下载 JSON 并读取验证，scope 为 offline_synthetic_demo，包含当前作答；样例副本位于 reports/browser-export.json。
