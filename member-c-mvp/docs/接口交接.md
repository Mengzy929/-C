这份接口是本地独立版本。尚未得到 A/B/D 确认，不能直接当作团队已冻结 schema。当前模块无需安装依赖；将 `qiyan_c` 和其资源加入团队的 Python 工程即可开始适配。

## B：编排、执行与前端

核心调用：

```python
from qiyan_c.teaching import decide, require_version
directive = decide(request, require_version(rules, pinned_version))
```

TeachingRequest：

| 字段 | 当前类型/语义 |
|---|---|
| intent | Intent：understand / locate / evaluate / reflect / off_topic（草案枚举） |
| dimension | Dimension：search / critical_reading / experiment_design / statistical_judgment / academic_expression |
| mastery | Mastery：novice / guided / independent |
| scaffold | 整数 0..3；这里只传递，不执行完整 fading |
| attempts | 非负整数，当前问题已完成的未通过作答次数 |
| giveup | bool；必须是用户确认查看解释后的服务端事实，不能将浏览器参数直接视为可信 |

返回 TeachingDirective：intent、hint_level、scaffold_level、dimension、must_ask、forbidden、rationale，以及本地扩展字段 rule_version/active。内部等级不能直接呈现在学生界面。

固定对象使用 frozen dataclass，列表字段在本地为 tuple。给 HTTP/JSON 使用时可用 `dataclasses.asdict()` 序列化；接收团队 TypedDict 时由适配层转换枚举与字段，不需要把主业务改成这里的命名。

### 输出检查与一次重写

```python
from qiyan_c.guard import detect

first = detect(candidate_text, directive, known_answers)
if first.action == "display":
    show(first.safe_text)
elif first.action == "rewrite":
    # 宿主通过 A 的 P1 执行一次重写；这里不调用模型。
    revised_text = host_rewrite(candidate_text, directive)
    final = detect(revised_text, directive, known_answers, rewrites_used=1)
    show(final.safe_text)  # 若仍违规，这里只包含固定兜底
else:
    show(first.safe_text)
```

`show`、`host_rewrite` 是说明宿主责任的伪代码，不是本包函数。不要先推送原始生成内容再运行 guard；MVP 建议生成完成并检查后展示。语义证据校验仍由 D 执行，guard 不能替代它。

### 阅读与判答

- `assess_demo` 只针对本包合成样文。真实判答服务返回 Assessment 后，可以继续使用 `submit/advance/explain` 状态转移。
- `ReadingState` 与团队研究阶段/Plan DAG 分离；它只管理当前论文的五层问题。
- `explain(..., confirmed=True)` 会清除 passed，要求当前层重答；查看解释不等于完成。
- `web/contracts.d.ts` 给出阅读卡的 props 草案。当前无 React 依赖，是原生 HTML/JS 预览。拿到 B 工程后可按其 React/组件库封装这些本域组件；不会要求 B 换框架。

## D：DocTree 与证据

- `DocTree` 包含文档 ID、版本、章节树、段落 ID、规范化文本与可选页码。
- `build_index` 用 DFS 建索引，重复章节/段落 ID 立即拒绝。
- `QuoteSpan` 是**段落内 Unicode 码点、左闭右开**的 start/end，绑定 doc_id/doc_version/paragraph_id/quote。
- `locate` 对版本、范围与原文进行精确匹配；失败不输出伪造高亮。
- 给 JS String.slice 使用时调用 `utf16_offsets`，明确转换为 UTF-16 码元；已覆盖中文、emoji 和换行测试。
- 不在本模块内改变 D 的原文规范化方案；双方应对齐后再生成 span。
- 本包没有 Verdict/Evidence 真值校验；题目能定位不意味着观点得到证据支持。

## A/D：学习事件、存储与复习

`reduce_events` 返回新 Ledger，不写存储。相同 ID 且内容相同的事件被去重；相同 ID 不同内容被拒绝。

`giveup_events(question_id, occurred_at)` 返回：

1. explicit_giveup：包含 -0.8 权重意向，不直接扣正式分数。
2. scaffold_failure：提供给后续 T3，不在这里改变档位。
3. review_requested：默认 5 天后，允许 3–7 天；标注 scheduled=false。

纯函数不读取时钟；调用方传入带时区 ISO 时间。重试时应重用原事件内容或使用幂等键，不应将同一事件换一个时间重新提交。跨请求、跨进程的“只写一次”由有持久化能力的宿主保证。

本地 Ledger 的作用域为单个演示会话，示例 question_id/event_id 不是跨学生全局唯一 ID。正式写库时必须由宿主加入 student/thread/本次题目实例的命名空间，不能把同名问题的事件跨学生去重。
